Medical Insurance Cost Prediction
Python · Pandas · Scikit-learn · Seaborn
Built a complete machine learning pipeline to analyze and predict medical insurance charges using a dataset of 1,338 patient records.

Performed exploratory data analysis with correlation heatmaps and regression plots
Encoded categorical features and selected the most predictive variables
Built and compared a Decision Tree Regressor and Random Forest Regressor
Identified smoking status, BMI, and age as the top drivers of insurance costs

Outcome: Decision Tree model with optimized leaf nodes achieved the lowest Mean Absolute Error.
